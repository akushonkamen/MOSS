# MOSS 系统架构

## 1. 整体架构

MOSS是一个基于Python的智能家居控制系统，采用微服务架构设计。系统主要由以下几个核心组件构成：

### 1.1 核心服务
- LLM服务：负责自然语言理解和指令解析，包含DecoderAgent和ExpertAgent
- 设备控制服务：管理和控制智能设备
- 语音识别服务（STT）：将语音转换为文本（计划中）
- 语音合成服务（TTS）：将文本转换为语音（计划中）

### 1.2 通信机制
- REST API：提供标准的HTTP接口
- WebSocket：实现实时通信和状态推送
- mDNS：实现设备自动发现和注册
- 进程间通信：基于HTTP的设备服务器与客户端通信

## 4. 通信流程

### 4.1 设备控制流程
1. 用户输入自然语言指令
2. DecoderAgent理解用户意图
3. ExpertAgent生成控制动作
4. 设备客户端执行函数调用
5. 设备服务器处理命令
6. 返回执行结果
7. 更新设备状态

### 4.2 状态同步流程
1. 设备状态变更
2. 服务器推送更新
3. 客户端接收更新
4. 更新本地状态缓存
5. 触发状态回调

### 4.3 设备发现流程
1. 设备服务器启动时注册mDNS服务
2. 设备客户端启动设备发现服务
3. 发现服务监听设备注册事件
4. 检测到新设备时触发回调
5. 客户端更新设备连接信息
6. 设备离线时自动清理
